# Couchside icon concepts

Four alternatives created with the built-in ImageGen tool on October 1, 2026.
Open `index.html` for a comparison at Home Screen and browser-tab sizes, or view
`comparison.png` for the four concepts together.

[Round 2](round-2/index.html) refines the preferred directions with the current
amber-to-coral colors and richer depth. Its [files and prompts](round-2/README.md)
are saved separately so the first round stays available for comparison.

| Option | Direction | Exact generation prompt |
| --- | --- | --- |
| 01 Soft Seat | Rounded graphic sofa with amber-to-coral cushions | [prompt](01-soft-seat/prompt.txt) |
| 02 Screen Seat | One integrated screen-and-sofa emblem | [prompt](02-screen-seat/prompt.txt) |
| 03 Afterglow | Sculptural warm sofa with soft dimensional lighting | [prompt](03-afterglow/prompt.txt) |
| 04 Couchside C | Bold C monogram with a sofa-shaped lower seat | [prompt](04-couchside-c/prompt.txt) |

Every folder includes the original 1254-square `master.png`, 512- and
192-square app PNGs, a 180-square Apple touch icon, an opaque 512-square
maskable icon, 16/32/48-square favicon PNGs and a three-size `favicon.ico`.
All formats use the same artwork. The artwork fits within the central
80%-diameter safe circle for maskable icons; platforms supply the outer crop.

`sh designs/app-icons/export.sh` regenerates the platform files with ImageMagick.
The originals and exact prompts are preserved. Sculpted C, option 07 from
Round 2, was selected for production on October 1, 2026. Its production copies
and icon generator live in `couchside/assets/brand`. All eight concepts remain available
for comparison.
